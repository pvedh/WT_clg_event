
# Experiment 1 – CRUD Backend using Node.js and Express

## Aim
To develop a simple backend application using Node.js and Express.js that supports CRUD operations (GET, POST, PATCH and DELETE).

## Software Tools Used
- Node.js
- Visual Studio Code
- Express.js
- Postman

## Description
Developed a Student Management API to add, retrieve, update and delete student records. Data is stored in an in-memory array.

## API Endpoints

| Method | Endpoint | Operation |
|---|---|---|
| GET | /students | Retrieve all students |
| GET | /students/:id | Retrieve one student |
| POST | /students | Add student |
| PATCH | /students/:id | Update student |
| DELETE | /students/:id | Delete student |

## Result
The Student Management Backend was successfully developed using Node.js and Express.js. All CRUD operations were implemented and tested successfully using Postman.
